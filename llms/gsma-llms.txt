# GSMA

> The GSMA is the London-headquartered global trade body for the mobile industry, representing around 750 mobile network operators and about 400 companies in the wider mobile ecosystem, and the organiser of MWC Barcelona. In the telecom API value chain it is the standards and commitment layer: it operates no production network API endpoints of its own. Its GSMA Open Gateway initiative is the memorandum of understanding under which 69 operator groups, representing 78% of global mobile connections, commit to exposing a common set of network APIs, while the specifications themselves are authored in the Linux Foundation's CAMARA project. The GSMA republishes 17 complete CAMARA OpenAPI 3.0.3 documents anonymously on open-gateway.gsma.com, runs a live public deployment map of 607 launched API instances across 80 operators and 65 countries, and runs a second, fully open developer portal for the GSMA Mobile Money API at developer.mobilemoneyapi.io.

Generated by API Evangelist on 2026-07-25 from the api-evangelist/gsma repository. No GSMA-published llms.txt exists: /llms.txt returns 404 on www.gsma.com and open-gateway.gsma.com.

## What to know before calling anything

- The GSMA hosts no API endpoints. Every Open Gateway OpenAPI declares a templated `{apiRoot}` server variable whose default is a placeholder (`http://localhost:9091`, `https://example.com:443`). The real base URL belongs to an operator or an aggregator. Live deployments are listed at https://open-gateway.gsma.com/map and in the JSON feed at https://d3bj8knxlstxyw.cloudfront.net/assets-map-launches.json
- Authorization for Open Gateway APIs is OpenID Connect against the operator's authorization server, with per-operation CAMARA scopes (30 distinct scopes across the 17 specs). The `openIdConnectUrl` published in every spec is the CAMARA placeholder `https://example.com/.well-known/openid-configuration`.
- The GSMA Mobile Money API is a separate programme with separate conventions: pre-shared `X-API-Key` + `X-Client-Id` headers, an optional end-user `X-User-Bearer` token, `X-CorrelationID` for idempotency and `X-Callback-URL` for asynchronous results.
- Neither programme returns RFC 9457 problem+json.

## APIs

- [GSMA Open Gateway developer portal](https://open-gateway.gsma.com/): 17 CAMARA API documentation pages, anonymous, no login
- [GSMA Open Gateway API reference index](https://open-gateway.gsma.com/docs): seven categories — Authentication and Fraud Prevention, Location Services, Device Information, Communication Quality, Payments and Charging, Computing Services, Communication Services
- [GSMA Mobile Money API](https://developer.mobilemoneyapi.io/api-versions-1.2/): OpenAPI 3.0.0, version 1.2.0, 53 paths across Transactions, Quotations, Accounts, Bills, Debit Mandates, Links and Authorisation Codes
- [GSMA Open Gateway deployment map](https://open-gateway.gsma.com/map): live map of launched API instances
- [GSMA Open Gateway API descriptions](https://www.gsma.com/solutions-and-impact/gsma-open-gateway/gsma-open-gateway-api-descriptions/): the full catalogue, including APIs with no published specification
